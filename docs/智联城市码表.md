# 智联招聘城市码（jl）

**实测得出** —— 2026-10-28 在本机用
`bb site zhaopin/search <关键词> --city <码> --json` 逐个码试，
看返回岗位的 `area` 城市名。

**验证脚本**：`bash scripts/verify-city-codes.sh`
（改了 `src/job_radar/city_codes.py` 必须重跑）

## 怎么用

在「设置 → 好岗好找 → 筛选条件」页的「抓取城市」里选城市名，
或直接改插件配置 `plugins.entries.job-radar.settings.cities`：

```yaml
cities: [重庆, 广州, 南宁, 桂林]   # 存城市名，不是码
```

后端在抓取时翻译成码（`city_codes.py`）。

## 重要：不能写逗号分隔

智联的 `--city` **只认一个码**。传 `"551,763"` 会**静默退化成全国**
（实测返回北京/保定/上海，完全没限定城市）。

所以插件**逐个城市抓**，每个城市跑一遍所有关键词。

## 规律

- **3000 段 = 地级市**，每 5 个码一个城市
- 段内不同码对应**同城的不同区县**
- **500 段 = 直辖市/省会**
- 区域码会**混进邻近城市**（538 上海会带宁波/湖州/大连/沈阳/青岛）

## 扫码方法

```bash
export HERMES_HOME="${HERMES_HOME:-$LOCALAPPDATA/hermes}"
BB="$HERMES_HOME/tools/bb-browser/bb.sh"
for code in 3150 3155 3160 3165; do
  printf "city=%-6s " "$code"
  bash "$BB" site zhaopin/search "运营" --city "$code" --json \
    | python -c "
import sys,json
from collections import Counter
d=json.load(sys.stdin); r=d.get('result',d)
js=r.get('jobs') or []
print(Counter([j.get('area','?').split()[0] for j in js]).most_common(2))
"
done
```

约 6 秒一个码。`count=0` 说明该城市该关键词没岗位，换关键词再试。
