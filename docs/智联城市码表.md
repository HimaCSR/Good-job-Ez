## ⚠️ 别用「区域码」

智联有两套码：**区域码**（5xx 段）和**城市专码**（6xx/7xx/8xx 段）。

**区域码抓回来是邻近城市**，有的根本不是那个城市：

| 城市 | 区域码 | 实际抓到 | 城市专码 | 实际抓到 |
| --- | --- | --- | --- | --- |
| 佛山 | 763 | **广州** | **768** | 佛山 20/20 |
| 惠州 | 763 | **广州** | **773** | 惠州 20/20 |
| 无锡 | 3040 | **常州** | **636** | 无锡 20/20 |
| 苏州 | 3040 | **常州** | **639** | 苏州 20/20 |
| 成都 | 552 | 成都 9 / 眉山 4 / 德阳 1… | **801** | 成都 20/20 |
| 南京 | 539 | 无锡 6 / 南京 4 / 苏州 3 | **635** | 南京 20/20 |

→ 用户在设置页选「佛山」，抓到的是**广州**的岗位。
**静默发生，不报错、不警告。**

## 两个 SEO 页叫「长株潭」

智联把长沙和株洲合并成一个站点叫「长株潭」：

    https://www.zhaopin.com/changsha/ → 749 = 长沙
    https://www.zhaopin.com/zhuzhou/  → 750 = 株洲

**两个都要抓** —— 只抓一个会漏掉另一个。

## 区域码扫描（备选手段）

```bash
bash scripts/scan-all-city-codes.sh    # 扫 530~620 + 3000 段
```

**精度不如 SEO 页**（拿到的是区域码），
但能一次性覆盖所有候选码，适合「找某个码段里有没有某城市」。

**注意**：同一个城市有多个码，**要按「该城市岗位数最多」选**，
不能按「第一次遇到」选 —— 否则 539 会被记成「无锡」（实测 539 抓到无锡 6 / 南京 4 / 苏州 3）。

## 怎么用

在「设置 → 好岗好找 → 筛选条件」页的「抓取城市」里选城市名，
或直接改插件配置 `plugins.entries.job-radar.settings.cities`：

```yaml
cities: [重庆, 广州, 南宁, 桂林]   # 存城市名，不是码
```

后端在抓取时翻译成码（`city_codes.py`）。

## 重要：不能写逗号分隔

智联的 `--city` **只认一个码**。传 `"551,763"` 会**静默退化成全国**
（实测返回北京/保定/上海，完全没限定城市）。

所以插件**逐个城市抓**，每个城市跑一遍所有关键词。

## 规律

- **3000 段 = 地级市**，每 5 个码一个城市
- 段内不同码对应**同城的不同区县**
- **500 段 = 直辖市/省会**
- 区域码会**混进邻近城市**（538 上海会带宁波/湖州/大连/沈阳/青岛）

## ⚠️ 区域码会带邻近城市

**成都 552 实测**：抓到 20 条，主城市成都（9 条），**其余是四川周边**
（眉山 4 / 德阳 1 / 泸州 1 / 广元 1 / 雅安 1）。

→ **期望城市是「成都」时，眉山的岗位也会拿到城市分**（子串匹配）。
这不是 bug，是智联区域码的特性 —— 想更准可以看岗位 `area` 的第一个词。

## 一次扫出全部城市码（区域码，精度不如上面）

**比「一城一城扫」快一个数量级** —— 一城一城扫是 N 座城市扫 N 遍，
同一个码被重复请求 N 次（既慢又容易触发风控）。

```bash
bash scripts/scan-all-city-codes.sh    # 扫一遍（约 8 分钟，150 个码）
```

覆盖 **530~620 整个 5xx 段** + 3000 段（每 5 个一个城市）。
5xx 段基本连续 —— 之前只扫了几个点，所以漏了西安/武汉/长沙/郑州。

结果写到 `docs/智联城市码实测.json`。

## 扫码方法

```bash
export HERMES_HOME="${HERMES_HOME:-$LOCALAPPDATA/hermes}"
BB="$HERMES_HOME/tools/bb-browser/bb.sh"
for code in 3150 3155 3160 3165; do
  printf "city=%-6s " "$code"
  bash "$BB" site zhaopin/search "运营" --city "$code" --json \
    | python -c "
import sys,json
from collections import Counter
d=json.load(sys.stdin); r=d.get('result',d)
js=r.get('jobs') or []
print(Counter([j.get('area','?').split()[0] for j in js]).most_common(2))
"
done
```

约 6 秒一个码。`count=0` 说明该城市该关键词没岗位，换关键词再试。
