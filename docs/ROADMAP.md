## 下一步（按优先级）

### 1. 简历匹配优化 ✅（2026-10-27 完成）

**目标**：点岗位卡的「简历匹配优化」，读该岗 JD，生成一份针对它的简历。

四步，每步可中止：

| 步 | 动作 | 约束 |
| --- | --- | --- |
| 1 | 读该岗位 JD 全文 | 从已登录的浏览器取，不重新抓列表 |
| 2 | 挑出 JD 核心要求 | 技能 / 学历 / 年限 / 关键词 |
| 3 | 对照用户经历，标出可写进简历的点 | **只重组用户写过的内容，不编造** |
| 4 | 按模板生成简历 | 模板来自「用户简历」模块 |

生成 ≠ 投递。生成结果先给预览，用户确认后才保存/导出。

**实现说明**：
- 列表页不返回 JD，优化时**按需抓一次详情页**（`bbclient.fetch_detail`）
- JD 的 tags 常粘连（`CSSJavaScriptERP`）→ 已知技能 + camelCase + 全大写三层切分
- 「经验不限」不当作 0 年
- 依据只标「第 N 条」，不重复贴原文 —— 原文另存 `basis_text`

### 2. 简历模板库 ✅（4 套内置完成；上传转换 ⬜）

- 4 套内置模板：classic 经典单栏 / modern 现代双栏 / tech 技术极客 / acad 学术风
- 模板可多选，「已选 N 套」实时更新
- **只有一处上传入口**：模板库右下角的「＋ 上传模板」格子
- 上传支持 `.docx` / `.pdf` / `.png` / `.jpg`，**转换全在本机完成，不调大模型**
  - Word：抽版式参数（页边距/字号/栏数/字体）→ HTML 模板（精度最高）
  - PDF / 图片：按视觉还原成「底图 + 文字层」混合模板
- **统一存 HTML 模板**：内置和上传的用同一份 HTML + CSS 结构，
  缩略图 = 同一模板的缩小渲染，一套渲染器吃下所有模板
- 智能选模板：读 JD 后由 Agent 挑版式

**已完成**：4 套内置模板 + 缩略图与输出同源（同一份 HTML 渲染）。
**未完成**：`.docx` / `.pdf` / 图片的**上传与转换**（Word 需 `zipfile` + XML 解析，
环境无 `python-docx`；HTML→PDF 走 Chrome headless 已打通）。

### 3. 投递流程 🔄（UI 完成，闸门未做）

**已完成**：弹层按匹配分排序历史简历、默认选最高分、明确提示
「选定只是用哪份简历，不等于授权投递」、跳转招聘网站投递。
**未完成**：三道门（每站开关 / 一次性令牌 / 每日上限）还没实现，
真正「投出去」的动作也没做 —— 目前只到「选定 + 跳转」。

**两态设计，不做第三种：**

| 场景 | 用户看到什么 | 系统做什么 |
| --- | --- | --- |
| 该岗位做过简历匹配优化 | 点「投递简历」→ 直接投优化后那份 | 标记 `optimized`，不再询问 |
| 没做过 | 点「投递简历」→ 弹历史简历推荐，每份显示**对该岗的匹配分** | 用标签 × 岗位要求打分排序，用户挑一份 |

> 没有「没有历史简历 → 引导去优化」这个分支。用户自己会判断 ——
> 列表为空时自然显示空列表。

**三道门**（不管走哪条路都要过）：

```
每站「允许投递简历」开关（默认关）
  → 一次性确认令牌（5 分钟有效，绑定 job_id）
    → 该站每日上限
```

选了历史简历**不等于**授权投递 —— 选定后还要走确认。

### 4. 用户简历档案 🔄（存储完成，列表 UI 待补）

**已完成**：`resumes` 表 + PDF 归档 + 标签 + 历史简历 × 岗位匹配分。
**未完成**：档案列表的完整 UI（预览 / 下载 / 设为默认）、投递统计（投了几家、几家回复）。
- 自动打标签：岗位方向 + 命中技能 + 目标岗位关键词
- 标签就是后续简历评分推荐的依据
- 每份记录：文件名 / 日期 / 用的模板 / 投递几家 / 几家回复 / 标签
- 操作：预览、下载、设为默认

## 不打算做的事

写下来是为了以后别反复讨论。

| 不做 | 为什么 |
| --- | --- |
| 让插件自己登录招聘网站 | 复用你浏览器里的登录态更真实，也不碰你的密码 |
| 把评分改成调 LLM | 本地规则够用，不烧 token，行为可预测 |
| 绕过招聘站的风控 | IP 不会因为独立 profile 而改变，被限流了该等该降速 |
| 自动投递（无确认） | 投递不可逆，必须你点头 |
| 简历文件发给大模型 | 个人信息外泄风险。例外：「AI 根据经历推荐」传的是摘要不是原文 |
| 把站点适配器放进公开仓库 | 里面有写操作，公开等于邀请别人用你的账号乱来 |
